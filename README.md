  Software Engineering Methods (SEM) Project

Professor: Andreas Steyven
Team size: 4

This project was part of our Software Engineering Methods (SEM) course, designed to develop our teamwork, software development, and project management skills. We worked in a group of four, which helped us learn how to collaborate effectively while using GitHub without interfering with each other’s work.

Key Learnings and Technologies

Programming & Frameworks: Java (similar to C# in syntax), Docker, Hibernate

Database Integration: Connected our application to a database, learning advanced SQL queries to provide users with population statistics (e.g., how many people lived in a certain area)

Project Management & Collaboration:

Scrum methodology: stand-ups, regular online meetings, and in-person support for teammates

Task management using Zube integrated with GitHub

Branching strategies to divide work and maintain safe code checkpoints

Weekly contribution tracking sheets and team code of conduct

Development Practices

Clean coding principles and MVVM architecture for maintainable code

UML diagrams, user stories, use cases, and scenarios to model application functionality

Git & GitHub:

Gitignore and file management best practices

Build badges to indicate project status

GitHub CLI for testing project upon code push

Project Outcome

The final deliverable was an interactive application that allowed users to browse population data via a menu system and select questions to query the database. The project emphasized team collaboration, software engineering best practices, and real-world development workflows.
